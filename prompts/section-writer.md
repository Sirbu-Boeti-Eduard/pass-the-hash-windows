# Section Writer (project-specific)

Use one section at a time. Fill the brief, paste the section's skeleton file, and nothing else
from the paper — the writer should not see material from sections it is not writing.

---

## Brief

```
Section:        <e.g. 4.2 Computing a valid response without the password>
Page budget:    <e.g. 1.0>
Job:            <the single thing this section must establish>
Claim:          <the one sentence a reader should be able to repeat afterwards>
Available:      <lab artefacts by file name | citations by bib key | "none yet">
Must not assume:<terms defined later in the paper>
Figures:        <fig keys this section may reference>
```

## Instructions

Write the section to the brief above. Constraints:

- The paper's spine: Windows authenticates possession of *key material*; the password is only
  one way to obtain that material.
- Every protocol term used must already exist in the Background chapter's vocabulary, or be
  defined here in one clause.
- No sentence that could appear in a vendor blog post.
- Cite only from the keys provided. Missing citation → `[[CITE: what needs sourcing]]`.
- Missing evidence → `[[EVIDENCE NEEDED: which artefact, from which scenario]]`.
- Section ends on the last claim, not on a summary of the section.
- Respect the page budget within ±20%. State the actual length you produced.

Deliver the prose, then a list of the assumptions you made that the brief did not cover.
